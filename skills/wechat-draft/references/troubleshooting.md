# 故障与权限

## 常见错误

- `40164`：调用出口 IP 不在白名单。添加报错中 `invalid ip` 后面的地址，不要照抄其他查询工具显示的地址。
- `40001`：AppSecret 不正确或已失效。重新核对配置；不要在对话中粘贴密钥。
- `48001`：目标账号没有相应接口权限。以脚本真实返回和微信开发者控制台为准。
- `76022`：查询的接口路径对当前账号无权限。
- `40007`：封面素材无效或已被删除。
- `41005`：图片文件不存在或未被接口接收。

## 权限检查如何理解

`--check-permissions` 使用微信的接口额度查询，只读取以下能力，不发送文章：

- `draft/add`：创建草稿。
- `freepublish/submit`：公开发布，但不会主动推送给粉丝。
- `message/mass/sendall`：群发给粉丝。

公开发布和群发不是同一件事。即使草稿接口可用，也不代表另外两个接口可用。

## 当前 Bot 的边界

Bot 只包装草稿创建与更新。即使账号将来获得发布或群发权限，也不要自动扩大功能；必须由用户明确要求新的能力和验收标准后再开发。
