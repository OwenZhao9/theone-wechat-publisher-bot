# 公众号浏览器发表

公众号后台是网页。本技能使用 TheOne 内置 Browser Use，也就是能打开、读取、点击网页的浏览器工具；不使用 Computer Use，也不把 Jev 当作浏览器控制工具。

## 使用条件

1. 只有用户明确要求发表、群发或设置定时时才操作公众号后台。只要求写文章或进入草稿箱时，不使用本技能。
2. 先确认目标草稿已经真实存在；需要修改文章时，先使用 `wechat-draft` 更新草稿。
3. 打开 `https://mp.weixin.qq.com/`。如果 Browser Use 不可用，说明缺少的是 TheOne 内置浏览器工具，不改用模拟结果。
4. 如果页面要求登录、扫码、验证码或其他身份验证，停在该页面，请用户本人完成；不要读取、索要或代填密码、验证码。

## 操作流程

1. 登录后进入目标公众号的草稿箱，按文章标题定位草稿。标题相同或无法唯一确定时，请用户选择，不猜测。
2. 打开草稿并检查标题、封面、摘要和正文是否与本次任务一致。页面显示的内容不一致时停止，说明差异。
3. 根据用户要求选择立即发表、群发或定时。设置定时时，使用用户指定时区；用户只说“明天”等相对日期时，把换算后的完整日期、时间和时区显示出来。
4. 到达最后的发表、群发或确认定时按钮前停止，向用户列出：公众号、文章标题、执行动作、计划时间和时区。取得用户确认后才能进行最终点击。
5. 最终点击后重新读取页面，只在页面明确显示成功、已群发或已设置定时后报告成功。保留公众号后台标签页供用户查验。

## 安全边界

- 不绕过验证码、登录保护、安全提示或平台限制。
- 不因为 API 没有发布权限就声称网页也不能发表；两条路径分别按真实页面和真实接口判断。
- 不点赞、关注、评论、发送其他消息，也不修改公众号设置。
- 页面结构变化、草稿不唯一、时间无法确认或出现错误时停止并说明，不盲点、不伪造结果。
